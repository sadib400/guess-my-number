# 🎯 Guess My Number

A fun multiplayer number guessing game for couples and friends — play together on the same device, online with a friend, or solo against the computer.

## 🕹️ Play Now

**👉 [Click here to play](https://sadib400.github.io/guess-my-number/GuessMyNumber.html)**

## 🎮 Game Modes

- **Play Together** — Pass the device around. 2–6 players, each picks a secret number and tries to guess the others'.
- **Play Online** — Host a room and share the code with a friend. Play in real-time over the internet.
- **vs Computer** — Single player. Pick your secret number, then try to guess the computer's while it hunts yours down using smart binary search logic.

## 📖 How to Play

1. Each player secretly enters a number within the agreed range (default 1–100).
2. Take turns guessing each other's numbers.
3. After each guess you'll get a hint: **Higher** or **Lower**.
4. First to guess all opponents' numbers wins! 🏆

## ✨ Features

- Neumorphic design that changes color per player turn
- Works entirely in the browser — no install, no account
- Online multiplayer via WebRTC (PeerJS)
- Smart bot AI using binary search strategy
- Animated thought bubble showing the computer's reasoning
- Works on mobile and desktop
